# AI-Powered-Student-Career-Coding-Placement-Platform
PlacementHub – Placement Management Platform

Overview

PlacementHub is a full-stack placement management web application designed to help students explore job opportunities, apply for jobs, track application statuses, and practice coding questions. It also provides an admin dashboard to manage job listings, students, applications, and coding questions.

The project aims to make the placement process more organized and convenient for both students and administrators.

Features

Admin Module

- Secure Admin Login
- Add, view, edit, and delete job listings
- Manage student records
- View student job applications
- Update application status
- Manage coding questions
- Manage coding test cases

Student Module

- Student Registration and Login
- Browse available jobs
- Search job opportunities
- Apply for jobs
- Submit resume links
- View submitted applications
- Track application status
- Update profile
- Change password

Coding Practice Module

- Browse coding questions
- View problem descriptions
- Select programming language
- Write and execute code
- Submit solutions against test cases
- View test case results
- Practice using custom input
- Track solved questions

Application Status

Applications can be tracked through different stages, such as:

- Pending
- Shortlisted
- Rejected

Administrators can update application statuses, and students can view their application progress.

Database

PlacementHub uses PostgreSQL to store and manage application data.

The database contains tables related to:

- Admins
- Students
- Jobs
- Applications
- Coding Questions
- Coding Test Cases
- Student Solved Questions

How to Run the Project

Prerequisites

- Java JDK
- Maven
- PostgreSQL
- IntelliJ IDEA (recommended)

Steps

1. Clone the project repository.
2. Open the project in IntelliJ IDEA.
3. Configure the PostgreSQL database.
4. Update the database configuration in "application.properties".
5. Configure the Judge0 API URL.
6. Run the Spring Boot application.
7. Open the application in your browser.
